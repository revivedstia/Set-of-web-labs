# Журнал студентов (лабораторная 4)

Журнал на странице: таблица с именем, баллом и статусом, форма добавления, проходной балл, удаление записей.

## Файлы

`index.html` — разметка, `app.js` — логика, `styles.css` — оформление. Flask не нужен.

## Запуск

Модули не загружаются по `file://`. В папке проекта: `python -m http.server 8000`, затем `http://localhost:8000`.

## Как устроено

Данные лежат в массивах `students` (записи `{ id, name, score }`) и `rejected`. Страница строится функцией `render()`: она очищает таблицу и заново рисует её из массива. Статус «Сдал» или «Пересдача» не хранится, а вычисляется в `render()` по текущему проходному баллу, поэтому смена порога не удаляет записи.

## Требования и где они выполнены

**Часть 1**
- Таблица с именем, баллом и статусом: `render()`.
- Проверка записей и порога: `validateScore`; записи с ошибкой попадают в `rejected`, неверный порог не применяется и показывает сообщение.
- Количество показанных и отклонённых: строка `#counts`, список причин в блоке «Отклонённые записи».
- Пустое состояние и повторное отображение: `render()` скрывает таблицу и показывает сообщение, если записей нет, и каждый раз перерисовывает всё заново.

**Часть 2**
- Форма и сообщения об ошибках: `<form id="add-form">`, ошибка выводится в `#form-error`.
- Порог меняет статусы: обработчик `input` на поле порога вызывает `render()`.
- Удаление по id, включая новые строки: у кнопки `data-id`, один делегированный обработчик на `tbody` фильтрует массив по id. Id выдаёт `createIdGenerator` (замыкание).
- Кнопка и Enter добавляют ровно одну запись: подписка только на событие `submit` формы, внутри `preventDefault()`. Отдельных обработчиков на клик и Enter нет.

## Проверка вручную

1. Добавьте студента кнопкой, затем другого клавишей Enter: каждый раз появляется одна строка.
2. Отправьте пустое имя, пустой балл, «abc», 105: ошибка в форме, счётчик отклонённых растёт.
3. Измените порог на 70, затем на 40: статусы меняются, строки остаются.
4. Удалите первую, добавленную и последнюю строки: удаляется нужная.
5. Удалите все записи: появляется пустое состояние. Добавьте запись: таблица возвращается.
