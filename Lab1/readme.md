# «Космическое агентство по продаже планет»

Одностраничник вымышленного сервиса, который продаёт путешествия на другие планеты.

Шапка: Главная / Планеты / О нас / Контакты

Большой hero: «Найди планету, которую назовёшь домом»

Карточки планет: Марс, Европа, Титан, Венера и т.д.

В каждой карточке: картинка, температура, расстояние, цена тура

Flexbox используется для расположения карточек

На мобильном карточки становятся вертикальными

Форма: «Забронировать консультацию»

Подвал: Educational project · HTML · CSS · Flexbox · Nginx
