# Обработка результатов студентов (лабораторные 3.1 и 3.2)

Модуль принимает массив студентов с баллами в виде строк, проверяет их и выдаёт принятые записи, отклонённые записи с причинами и статистику.

## Файлы

- `index.html` — страница запуска, подключает `app.js` как модуль.
- `app.js` — вся логика.
- `styles.css` — оформление страницы.

Flask и другие серверные части не нужны: достаточно статической раздачи файлов.

## Запуск

Модули не загружаются по `file://`, поэтому страницу нужно открыть по HTTP. В папке проекта:

```
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Вывод появится на странице и в Console (F12).

## Что реализовано

**Часть 1. Проверка данных и массивы**

- `validateScore` проверяет по порядку: пустую строку (после `trim`), преобразование через `Number` и `Number.isFinite`, диапазон 0–100. Пустоту проверяем до преобразования, потому что `Number("")` даёт 0.
- `processStudents` возвращает принятые записи (с числовым баллом), отклонённые (с причиной) и статистику. Исходный массив не изменяется.
- Среднее считается по числу принятых записей. Если их нет, выводится «нет оценок», деления на ноль нет.

**Часть 2. Функции**

- `createMinScoreFilter(min)` — фабрика фильтра с порогом в замыкании. Граница включена (`>=`).
- `createCheckCounter()` — счётчик проверок через замыкание. Каждый вызов даёт независимый счётчик.
- `demoThis()` — потеря `this` при извлечении метода и два исправления: `bind` и стрелка-обёртка.

Пустой массив: 0 принятых, среднее «нет оценок», 0 проверок. Набор без корректных баллов: 0 принятых, 2 отклонённых, среднее «нет оценок».

`lost()` в демонстрации `this` даёт `TypeError`: в строгом режиме `this` равен `undefined`.

## Разбор ошибки из чужого кода

В цикле `for (const score in scores)` переменная `score` получает не значения массива, а строковые ключи `"0"`, `"1"`, `"2"`. Из-за этого `total += score` склеивает строки (`"0012"`), а не складывает баллы, и среднее получается неверным (4 вместо 58,33), хотя программа не падает. Исправление: `for...of`, явное `Number(raw)` и проверка `scores.length > 0`.
